# Drawn in Code

Source code for the Shorts on **[Drawn in Code](https://www.youtube.com/@drawn_in_code)**: small horror films made entirely in Python.

Every frame and every sound is generated by the script. No footage, no stock audio, no AI images. ASCII characters, simulations and synthesized sound are the whole toolkit.

## Running them

You need Python 3.10+, **ffmpeg**, **espeak-ng** (for the voices) and the **DejaVu** fonts.

```bash
# Debian / Ubuntu
sudo apt install ffmpeg espeak-ng fonts-dejavu-core
pip install -r requirements.txt

python shorts/ink/ink.py          # writes shorts/ink/ink_in_water.mp4
```

Each script renders a 1080×1920, 30 fps MP4 next to itself. A render takes a few minutes on a normal CPU.

`shorts/common.py` holds the shared helpers: the ffmpeg video writer, fonts, captions, espeak voices and audio filters. Harmonograph Sigil predates it and is fully self-contained.

> **Windows/macOS:** the font paths in `common.py` point to the Linux DejaVu location. Change the `MONO`/`SERIF` paths at the top to wherever DejaVu is installed on your machine.
