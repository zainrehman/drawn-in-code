# Harmonograph Sigil

▶ [Watch on YouTube](https://youtube.com/shorts/7yDl7bbC1U8)

Four simulated pendulums drive a pen that slowly traces an intricate sigil. The same four pendulums are the soundtrack: each one is a tone. When they stop, the pen doesn't.

**How it works**
- A classic harmonograph: the pen position is a sum of damped sine waves.
- Each pendulum's frequency and damping also drive an oscillator, so what you hear is what draws the picture.
- This script is fully self-contained and doesn't use `common.py`.

```bash
python shorts/sigil/sigil.py    # -> harmonograph_sigil.mp4
```
